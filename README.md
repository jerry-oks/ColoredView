# ColoredView
Приложение позволяет менять основной цвет View с помощью слайдеров или текстовых полей.

> Это же приложение на SwiftUI: [перейти >](https://github.com/jerry-oks/ColoredView2)

## Стэк
+ Xcode
+ Swift
+ UIKit
+ Storyboard
+ Auto Layout

## Цели и задачи
+ изучение передачи данных между экранами и изменения состояния элементов UI 
+ работа с UISlider, UITextField, UIButton
